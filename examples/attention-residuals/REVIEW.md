# 导读页自查:用这个 skill 讲 Attention Residuals,哪里损失了可读性和可理解性

对象:`attention-residuals.html`(源码 `src/make.py`),讲解 Kimi Team 的 Attention Residuals(arXiv 2603.15031)。
这是第二版。第一版的图只画了"谁连谁",没有体现计算关系,被你否掉。这一版重做了图、视觉和构建方式。

## 这一版改了什么

1. **图换成算符级计算图。** 每个运算(RMSNorm、点积打分、softmax 分母、权重、加权、求和)一个框,框内用 KaTeX 写算式,线是真实数据流。三个标签页对应标准残差、完整 AttnRes、分块 AttnRes。
2. **记号对齐论文。** 现在用论文的 `v_i`、`w_l`、`α_{i→l}`、`b_n`、式 (2)(3)(4)(5)(6)。我读到了 ar5iv 的全文,范围是摘要至 §5.4 开头。
3. **纠正了第一版的两处错。** 第一版把 `v_0` 当成层输出的下标起点,但论文里 `v_0 = h_1`(词嵌入)。第一版的"块大小 2"例子也没和论文式 (6) 对上。
4. **统一视觉。** 页面全部用 `tokens.css`、`base.css`、新增的 `schematic.css`,不再内联各写各的样式。字体子集化后嵌入,KaTeX 构建时预渲染,页面不引用任何外部资源。
5. **删掉图下的说明文字。** 图例写进讲义 0.2,术语点击展开。

## 仍然损失的可读性

1. **我没读到的部分。** §5.4 其余、§6(深度方向线性注意力与 softmax 注意力的对应)、附录。讲义 1.3 只能写"这个论证在 §6,我没有读到"。页脚已注明。
2. **图只能讲一层的输入怎么算。** 论文的核心证据(损失降了多少、开销多少)在讲义的表里,和图没有联动。图与证据之间没有线。
3. **模型细节没画。** 分块版的"部分和 b_n^i"在块内逐层更新,图里只画了求第 4 层输入的一个瞬间,没有画块内循环。
4. **窄屏丢掉空间信息。** 1000px 以下改成按阶段分组的清单,线没了,"谁接谁"只能靠每项的文字,看不出连线。
5. **三个模式要靠切换对比。** 读者一次只看到一张。完整版和分块版共用同一套 7 列,同一种运算停在同一列,能减轻记忆负担;标准残差只有 3 列,对不上。三者没有并排。
6. **术语展开的发现性没有验证。** 带下划线的词能点,但没有读者测试过他们会不会去点。
7. **没有真实读者看过。** 上一版冷读过文字(子代理,纯文本),这一版的图和讲义没有重做冷读。
