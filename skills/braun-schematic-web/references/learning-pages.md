# 学习 / 讲解类页面怎么套

- **概念页**:主视觉 = 概念名(窄体大字 `.big`)+ 一句话定义;下面按区块用细线分段(`.section`):是什么 → 为什么 → 怎么用 → 例子 → 易错点。
- **定义 / 术语表**:两栏,左栏术语用 `.label` 样式,右栏解释;行与行之间一条 `--rule`。窄屏自动变成单栏。
- **步骤 / 流程**:只有真的是先后顺序时才编号;编号用 28px 的描边方框,已完成实心墨色加对勾。
- **对比**:用表格(窄屏自动堆叠),不用并排卡片。表头一条墨线,行间细线。
- **公式**:用 KaTeX(见 `katex.md`);**代码**:用 `.code`;关键符号可用 `.hl` 下划线标出。
- **掌握程度 / 进度**:用刻度条 `.meter`,指针即当前位置。
- **知识点状态**:用小方块指示灯标签 `.tag`(已掌握 / 需复习 / 未学)。
- **时间线**:一根竖向 1px 细线,事件处一个 7px 的墨色方块,日期用窄体数字。
- **示意图**:细线 SVG,墨色描边,只有"最关键的那一个元素"用陶土色;SVG 用 `viewBox` 和 `max-width:100%`。
- **测验 / 闪卡**:选项用 `.tier`(1px 描边方框,选中 = 墨色描边 + 下方陶土线);对错用"小方块 + 文字"表达,不用大面积红绿填充。
- **目录 / 导航**:左侧纯文字列表,当前项 = 浅 `--tint` 底 + 下方一条陶土线;不要图标方块;窄屏折叠成顶部一行。
- **数据看板**:页头一行标题;主视觉放最重要的一个窄体大数字(顶上 2px 墨线);指标用小标签 + 窄体数字 + 说明,区块之间只有细线与留白。
