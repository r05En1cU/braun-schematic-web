# 改造旧页面(已有页面改成这套风格)

**重写,不要只覆盖。** 在旧样式表后面追加"新规则覆盖旧规则"会留下大量残留:旧选择器更具体时(例如 `.hero .hl`)会盖过新规则,荧光笔、渐变、白色半透明、悬停旋转都会漏出来。

1. 把组件样式表**整体重写成一份干净的新样式**,旧的视觉规则一条不留,只保留必要的布局骨架。
2. 页面里的内联样式和页面内 `<style>` 也要清:写死的旧色值、`rgba(255,255,255,…)`(旧深色卡片上的写法)、`background:var(--pop)` 这种整块荧光底、`border-radius`、`font-size/weight` 的内联写法、套餐卡的旧描边/动画。
3. 图表脚本里的颜色、`rx`、`stroke-linecap:round`、平滑曲线、渐变填充要一并改。
4. 页面切换过渡(View Transition)整个删掉。
5. 改完做**残留扫描**,逐条确认:

```bash
grep -rnE "gradient|rgba\(255|class=\"[^\"]*\bhl\b|border-radius:[^0]|rx=|linecap=\"round\"|#[0-9A-Fa-f]{6}" *.html assets/*.js
```

6. 再用 `scripts/check_viewports.py` 在浏览器里遍历所有元素:计算后的圆角是否全为 0、SVG 有没有 `rx`/圆头、有没有横向溢出。一次跑太多页面会超时,分批并行跑。
7. 常见坑:
   - 选中态用"深色整行填充 + 浅色字",悬停把底色盖掉后字看不见 → 改成"加粗 + 下方陶土线"。
   - `overflow-wrap:anywhere` 加在 `td/th` 上 → 表格永远"放得下"而不堆叠;改用 `break-word`。
   - `.row > div { min-width: 0 }` 这类宽泛规则 → 让该换行的弹性行硬挤、反而溢出;只给确实会撑破的文本块加。
   - 写死宽度的输入框、不换行的弹性行、网格里的表格(没加 `min-width:0`)→ 手机上溢出。
